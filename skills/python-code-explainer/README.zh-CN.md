# Python Code Explainer（Python 代码解读器）

`python-code-explainer` 是一个可移植的 Skill：解读 Python 代码，并生成一份带详细中文注释的注解版 `.py` 文件。注解版输出**仍然是合法、可编译的 Python 文件**，可以继续作为文档阅读、diff 与归档。

English: [README.md](README.md)

## 它能做什么

对任意 Python 文件（或粘贴的代码片段、整个项目），生成一份注解版副本，固定为三段结构：

1. **文件头 —— 功能定性**：文件开头的详细中文介绍，包含一句话定性、模块职责、主要类与函数、输入输出、外部依赖、运行入口与关键设计。
2. **文件主体 —— 逐块注释**：每个最小但有含义的代码块（导入区、常量、类、函数、`if/for/try/with`、推导式、lambda 等）之后紧贴具体中文注释，解释“为什么 / 做什么”，而不是复述代码。
3. **文件尾 —— 不足与优化方向**：结尾一节给出具体、可执行的改进建议，覆盖可读性、性能、健壮性、安全、测试与兼容性。

## 为什么需要它

- 输出**仍是合法 Python 文件**：只加注释、不改动原逻辑，并用 `py_compile` 校验。
- 注释讲意图而非语法，注解版可以同时充当阅读文档与新人上手材料。
- 批量模式可扫描项目下所有 `*.py`，自动跳过虚拟环境、`__pycache__` 与已注解过的文件。

## 当前文件夹模式（删除旧文件）

当被解读的代码来自磁盘上已有的文件（尤其是当前工作目录内的文件）时，skill 会在注解版**成功写出并通过语法校验后删除原始文件**。安全规则：

- 删除**仅在**注解版成功写出且 `py_compile` 通过之后执行；任何一步失败都保留原文件并向用户报告。
- 只删除被解读的那一个源文件，绝不触碰其他文件。
- 删除结果会向用户汇报。

该模式保持目录干净，只留下注解版供阅读；如需保留原文件，请明确告知 Agent 跳过删除。

## 在编程 Agent 中使用

1. 将当前 Skill 文件夹复制到目标编程 Agent 支持的 Skills 目录。
2. 要求 Agent 解读你的 Python 代码，或为项目下所有代码文件生成注解版。
3. 阅读生成的 `*_annotated.py` 文件。

可直接使用的指令：

> 请使用 `python-code-explainer` Skill 解读 `foo.py`，在同一目录生成 `foo_annotated.py`；注解版通过语法校验后，按当前文件夹模式删除原始文件。

## 输出示例

给定 `foo.py`，skill 生成 `foo_annotated.py`：

```text
foo_annotated.py
├── 头部    # 《Python 代码解读》——功能定性（中文，UTF-8）
├── 主体    # 原代码 + 每个最小代码块之后的中文注释
└── 尾部    # # === 代码不足与可优化方向 === 不足与优化建议
```
